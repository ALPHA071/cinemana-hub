# 🎬 Cinemana Hub - منصة مشاهدة وتحميل سينمانا المباشرة

> **Cinemana Web Hub**: أداة ويب تفاعلية متطورة وخفيفة الوزن تتيح لك تصفح، مشاهدة، واستخراج روابط مقاطع شبكتي سينمانا (Cinemana Shabakaty) بجودات متعددة، مع مشغل فيديو مدمج يدعم عرض ملفات الترجمة العربية تلقائياً وبأعلى دقة.

---


## 📖 نبذة عن المشروع
تم تصميم **Cinemana Hub** ليقدم تجربة مشاهدة وتحميل سلسة وسريعة لمستخدمي شبكة سينمانا. تتيح لك المنصة البحث السريع عن أي فيلم أو مسلسل عبر الاسم، الرابط المباشر، أو معرف المقطع (Video ID)، مع توفير روابط المشاهدة والتحميل المباشر لكافة الجودات المتوفرة، بالإضافة إلى استخراج وتنزيل ملفات الترجمة بمختلف اللغات بصيغتي SRT و WebVTT.

---

## ✨ المميزات الرئيسية
* 🔍 **محرك بحث سريع ومرن:** ابحث مباشرة باسم العمل، أو الصق رابط سينمانا، أو ضع الـ ID الخاص بالمقطع للوصول إلى كافة تفاصيله فوراً.
* 📺 **مشغل وسائط سينمائي مدمج:** استمتع بمشاهدة الفيديو مباشرة داخل الصفحة دون الحاجة لمغادرة الموقع، مع مشغل سلس يدعم مختلف المتصفحات والشاشات.
* 💬 **دمج الترجمة التلقائي (Smart Subtitles):** تعرف فوري على الترجمات المتوفرة وعرض الترجمة العربية تلقائياً على الفيديو بدقة تزامن عالية، مع إمكانية التبديل بين اللغات بنقرة زر.
* 🎬 **خيارات جودة متعددة (Multi-Quality Stream):** استخراج وعرض جميع الجودات المتاحة من السيرفر (1080p FHD, 720p HD, 480p SD, 360p, 240p) مع روابط تحميل ونسخ مباشرة.
* 📑 **تحميل ومعاينة ملفات الترجمة:** تنزيل ملفات الترجمة المرافقة بصيغ (SRT / VTT) مع إمكانية المعاينة السريعة لنص الترجمة قبل التحميل.
* ⚡ **أداء فائق وخفيف (Zero Dependencies):** مبني بتقنيات الويب النقية (Pure HTML5 / CSS3 / Vanilla JS) في ملف واحد مستقل تماماً ولا يحتاج إلى أي خوادم خارجية أو مكتبات ثقيلة.
* 📱 **تصميم عصري متجاوب (Modern Dark UI):** واجهة داكنة مريحة للعين ومتناسقة بالكامل مع الهواتف الذكية والأجهزة اللوحية والشاشات الكبيرة.
